# Instituto Mão Amiga

Aplicativo mobile desenvolvido em React Native com Expo para apoiar o Instituto Mão Amiga no gerenciamento de doações, pontos de coleta e distribuição de alimentos.

## 📌 Sobre o projeto

Este projeto faz parte da disciplina de Desenvolvimento Mobile e será desenvolvido ao longo do semestre seguindo as sprints propostas pela disciplina.

## 🎯 Objetivo

Desenvolver uma aplicação capaz de:

- Gerenciar pontos de coleta e distribuição;
- Organizar o registro de doações;
- Facilitar o acompanhamento das famílias atendidas;
- Centralizar as informações em uma plataforma mobile.

## 🚀 Tecnologias

- React Native
- Expo
- JavaScript
- Node.js
- Git
- GitHub
